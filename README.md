# 📚 AI Study Planner

A beginner-friendly web application designed to help students organize their study schedules based on their subjects, exam dates, topics, and available study time.

This project is being developed step-by-step to understand how a basic web application can evolve into a **Generative AI application, AI Agent, and eventually an Agentic AI system**.

---

## 📌 Project Overview

Students often struggle to manage multiple subjects, topics, deadlines, and limited study time. Creating a proper study schedule manually can be difficult and time-consuming.

The AI Study Planner aims to solve this problem by providing a simple platform where students can enter their study requirements and generate an organized study plan.

The project will be developed progressively, starting with a basic web application and gradually introducing Generative AI and AI Agent capabilities.

---

## 🎯 Objectives

- Help students organize their study schedules.
- Provide a simple and user-friendly study planning interface.
- Generate personalized study plans using AI in future versions.
- Understand how Generative AI can be integrated into a web application.
- Understand how AI Agents use tools and perform tasks.
- Learn the basic flow of Agentic AI systems.
- Gain practical experience with AI coding agents and prompt-based development.

---

## ✨ Current Features

### Version 1 – Basic Study Planner

The initial version includes:

- Subject name input
- Exam date input
- Topics to study input
- Available study hours input
- Study information display
- Simple and beginner-friendly user interface

> AI functionality is not included in the initial version.

---

## 🤖 Planned AI Features

Future versions of the project will include:

### Version 2 – Generative AI

- AI-generated study plans
- Personalized daily schedules
- Topic prioritization
- Revision suggestions
- Study-time recommendations

### Version 3 – AI Agent

The system will gradually be converted into an AI Agent that can:

- Understand the student's study goal
- Break a goal into smaller tasks
- Use available tools
- Perform calculations
- Generate and modify study plans
- Respond to changing requirements

### Version 4 – Agentic AI

The long-term goal is to create an agentic study assistant that can:

- Analyze study progress
- Identify incomplete or weak topics
- Modify the study plan
- Recommend revision
- Use multiple tools
- Continuously work toward the student's study goal
