# ONE PAGE REPORT (OPR)

## Project Title
**AI Study Planner – Personalized and Intelligent Study Planning Assistant**

## 1. Introduction

AI Study Planner is a web-based application designed to help students organize their study schedules in a simple and effective manner. The system allows students to provide information such as subjects, exam dates, topics to study, and available study hours. Based on this information, the application aims to create a personalized study plan. The project will initially be developed as a basic web application and will gradually be enhanced with Generative AI and AI Agent capabilities.

## 2. Problem Statement

Students often find it difficult to manage their study time when they have multiple subjects, topics, and examination deadlines. Creating a balanced study schedule manually can be time-consuming and may result in poor time management, missed topics, or insufficient revision. There is a need for a simple and intelligent system that can help students plan their studies according to their individual requirements and available time.

## 3. Proposed Solution

The proposed system, AI Study Planner, will provide students with an easy-to-use platform for creating personalized study plans. Users will enter their subjects, exam dates, topics, and available study hours. The initial version will organize and display this information. In future versions, Generative AI will be integrated to generate personalized study plans, while AI Agent capabilities will allow the system to use tools, make decisions, and adapt the plan according to the student's progress and requirements.

## 4. Objectives

- To develop a simple and user-friendly study planning application.
- To help students organize their study time effectively.
- To generate personalized study plans based on user-provided information.
- To understand the practical use of Generative AI.
- To understand the concepts of AI Agents and Agentic AI.
- To gradually develop the application from a basic web application into an intelligent AI-based system.

## 5. Target Users

- College students
- School students
- Students preparing for examinations
- Students managing multiple subjects and deadlines

## 6. Key Features

### Initial Version
- Subject name input
- Exam date input
- Topics input
- Available study hours input
- Display of entered study information
- Simple and user-friendly interface

### Future AI Features
- AI-generated personalized study plans
- Topic prioritization
- Daily study schedule generation
- Revision recommendations
- Progress tracking
- Identification of unfinished or weak topics
- Automatic modification of study plans
- AI Agent with access to selected tools

## 7. Technology Stack

### Initial Version
- HTML
- CSS
- JavaScript

### Future Development
- Backend technology
- Generative AI / LLM API
- AI Agent framework
- Database
- External APIs or tools

## 8. Expected Outcome

The expected outcome is a functional web-based study planner that helps students organize their study activities. The project will also provide practical understanding of how a traditional web application can be gradually enhanced using Generative AI, AI Agents, and Agentic AI workflows.

## 9. Future Scope

The system can be further enhanced with:

- Student accounts and authentication
- Syllabus and document upload
- Calendar integration
- Study progress tracking
- Personalized learning history
- AI-based weak-topic analysis
- Voice-based interaction
- Automated study-plan modification
- Integration with educational resources
- Multiple AI tools for advanced agentic workflows

## 10. Conclusion

AI Study Planner aims to provide students with a simple solution for organizing their study schedules while serving as a practical project for understanding modern AI technologies. The project will be developed progressively, starting with a basic web application and evolving into a Generative AI-powered and eventually agentic study-planning assistant.
